# spec-load — 查看当前议题状态

## 定位

每次新对话的第一步。调 `spec_status()` 了解当前在哪，然后决定下一步走哪个岔路。

## 在哪选

这不是一个独立岔路。它是任何决策前的必选前导动作。

## 选择判断

直接调 `spec_status()` 查看返回：

| 返回 | 下一步 |
|------|--------|
| 「没有活跃议题」 | 引导用户：可选 `spec_start` 开启新议题 |
| 返回当前决议/待定决议/后续计划 | 向用户展示状态摘要，由用户决定： `spec_pause` / `spec_close` / `spec_abort` |
