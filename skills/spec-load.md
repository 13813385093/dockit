# spec-load — 查看当前议题状态

## 定位

每次新对话的第一步。调 `spec_status()` 了解当前在哪，然后决定下一步走哪个岔路。

## 在哪选

这不是一个独立岔路。它是任何决策前的必选前导动作。

## 选择判断

直接调 `spec_status()` 查看返回：

| 返回 | 含义 | 下一步 |
|------|------|--------|
| 「没有活跃议题」 | 当前无进行中的会议 | 引导用户：可选 `spec_start` 开启新议题 |
| 有活跃议题，含已完成决议 | 有议题进行中 | 向用户展示状态摘要（决议/待定/计划），由用户决定下一步：`spec_pause` / `spec_close` / `spec_abort` |
| 有活跃议题，无任何决议/待定/计划 | 议题刚创建，尚未讨论 | 继续引导用户讨论 |

展示状态摘要时，应突出：
- ✅ 已完成的决议数（如为 0 可省略）
- ❓ 待定的决议数（如有，引导用户优先讨论）
- 📌 后续计划数（如有）
